# HiDock Next has moved

This repository is retained as a historical archive. Active development has moved to two focused projects:

- [HiDock Next 2.0](https://github.com/sgeraldes/hidock-next-2) — the current Electron knowledge hub, including device sync, transcription, meetings, search, and AI-powered insights.
- [HiDock Light](https://github.com/sgeraldes/hidock-light) — the focused Python desktop app for people who want HiDock device management without the broader knowledge-hub functionality.

Please use the new repositories for downloads, documentation, issues, and pull requests. Existing history remains here for reference, but this repository is no longer the active development home.
